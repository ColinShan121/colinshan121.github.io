## Featured Project

**Freight Search** — A FastAPI and PostgreSQL freight-listing application with a
local browser dashboard for search and listing creation. Features include ranked
full-text search, case-insensitive route filters, equipment and status filters,
active-filter summaries, clear filters, Previous/Next pagination, input validation,
and listing retrieval and full updates through the API.

Built with Python, FastAPI, PostgreSQL, Psycopg, Docker Compose, and JavaScript.
The latest published project commit passed GitHub Actions PostgreSQL integration
CI. An earlier local milestone passed all 36 tests.

NATS, OpenSearch, asynchronous indexing, and recovery handling remain planned.
The application runs locally; no publicly hosted app or performance benchmarks
have been verified. The project screenshot contains fictional demonstration data.
